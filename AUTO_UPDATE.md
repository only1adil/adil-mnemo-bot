# 🔄 Автоматическое обновление слов в боте Mneme

Ваш бот теперь автоматически обновляется при изменении файла `words.json`. Это работает тремя способами:

## 1️⃣ **Проверка при запросе слов (РЕКОМЕНДУЕТСЯ)**
- **Как работает**: Каждый раз, когда пользователь нажимает "📚 Учить слова", бот проверяет, изменился ли файл `words.json`
- **Скорость**: ⚡ Мгновенно (если файл изменился, обновление происходит сразу)
- **Преимущества**:
  - Новые слова появляются в боте сразу же, когда вы их добавите
  - Не требует ждать следующего часа
  - Работает 24/7

## 2️⃣ **Периодическое обновление (каждый час)**
- **Как работает**: Бот автоматически синхронизирует слова каждый час в фоновом режиме
- **Функция**: `auto_sync_words()` в `bot.py`
- **Преимущества**:
  - Гарантирует, что все пользователи получат обновления
  - Полезно, если файл обновляется автоматически из другого источника

## 3️⃣ **Ручной перезапуск (не требуется)**
- Если вы хотите обновить немедленно, просто перезагрузите бот
- Функция `sync_words_from_json()` вызывается при старте

## 📋 Как добавлять новые слова

### Вариант 1: Через текстовый редактор (простейший)
1. Откройте `words.json`
2. Добавьте новые слова в конец массива (перед закрывающей `]`):
```json
{
    "id": 226,
    "word": "новое слово",
    "translation": "перевод",
    "association": "ассоциация",
    "example": "пример предложения",
    "ipa": "/транскрипция/"
}
```
3. Сохраните файл
4. **Готово!** Новые слова автоматически появятся в боте при следующем запросе на обучение

### Вариант 2: Через скрипт (для автоматизации)
Вы можете создать скрипт, который добавляет слова в `words.json`:

```python
import json
from pathlib import Path

def add_words(words_list):
    # Загружаем существующие слова
    with open('words.json', 'r', encoding='utf-8') as f:
        data = json.load(f)
    
    # Находим максимальный ID
    max_id = max(w['id'] for w in data)
    
    # Добавляем новые слова с новыми ID
    for i, word in enumerate(words_list):
        word['id'] = max_id + i + 1
        data.append(word)
    
    # Сохраняем обратно
    with open('words.json', 'w', encoding='utf-8') as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
    
    print(f"✅ Добавлено {len(words_list)} слов")

# Пример использования
new_words = [
    {
        "word": "amazing",
        "translation": "удивительный",
        "association": "А это меня изумляет",
        "example": "This is amazing!",
        "ipa": "/əˈmeɪzɪŋ/"
    }
]

add_words(new_words)
```

## ⚙️ Конфигурация

### Изменить интервал проверки файла
Если нужно проверять чаще (например, каждые 30 минут):

Отредактируйте в `bot.py` в функции `schedule_tasks()`:
```python
# Было:
scheduler.add_job(auto_sync_words, "interval", hours=1)

# Стало (каждые 30 минут):
scheduler.add_job(auto_sync_words, "interval", minutes=30)
```

### Отключить автоматическое обновление
Если нужно отключить периодическое обновление (оставив только проверку при запросе):

В `bot.py` в функции `schedule_tasks()` закомментируйте:
```python
# scheduler.add_job(auto_sync_words, "interval", hours=1, ...)
```

## 🚀 Дополнительные возможности

### Отслеживание удаленных слов
Текущая система добавляет новые слова, но не удаляет старые. Если нужно удалить слово:
1. Удалите его из `words.json`
2. Перезагрузите бот (или отредактируйте базу данных вручную через SQLite)

### Использование watchdog для отслеживания в реальном времени
Если нужно еще более быстрое обновление, можно установить `watchdog`:
```bash
pip install watchdog
```
