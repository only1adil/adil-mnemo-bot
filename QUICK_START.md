# ⚡ Быстрый старт: Автоматическое обновление слов

## 🎯 В двух словах

**Ваш бот теперь обновляется автоматически!**

Добавляете слова → Сохраняете файл → Слова появляются в боте (при запросе обучения)

---

## 📋 Три способа добавить слова

### 1️⃣ **Самый быстрый - редактировать JSON напрямую**
1. Откройте `words.json` в текстовом редакторе
2. Найдите последний элемент (последнее слово)
3. Добавьте запятую после `}` предыдущего слова
4. Вставьте новое слово:
```json
{
    "id": 226,
    "word": "butterfly",
    "translation": "бабочка",
    "association": "Баба летит как бабочка",
    "example": "The butterfly is colorful",
    "ipa": "/ˈbʌt.ər.flaɪ/"
}
```
5. **Ctrl+S** - сохраните
6. **Готово!** Новые слова появятся в боте при нажатии "📚 Учить слова"

### 2️⃣ **Удобный скрипт - интерактивно**
```bash
python add_words.py
```
- Выберите "1. Добавить одно слово вручную"
- Заполните данные
- Готово!

### 3️⃣ **Массовое добавление - из CSV или JSON**
```bash
python add_words.py
```
- Выберите "2. Добавить несколько слов из файла"
- Укажите путь к файлу
- Готово!

## 🔄 Как это работает

### Механизм 1: Проверка при запросе (ОСНОВНОЙ)
```
Пользователь нажимает "📚 Учить слова"
    ↓
Бот проверяет: Изменился ли words.json?
    ↓
Если да → Автоматически обновляет базу данных
    ↓
Пользователь видит новые слова!
```

### Механизм 2: Почасовая синхронизация (страховка)
- Бот проверяет файл автоматически каждый час
- Это гарантирует, что даже если пользователь долго не заходил - он получит обновления

## ❓ Частые вопросы

### Q: Нужно ли перезагружать бот?
**A:** Нет! Обновление происходит автоматически.

### Q: Когда появляются новые слова?
**A:** Сразу при следующем запросе обучения (нажатии "📚 Учить слова").

### Q: Что если я добавлю неправильный JSON?
**A:** Бот покажет ошибку в логах. Используйте `add_words.py` для безопасности.

### Q: Можно ли удалить слово?
**A:** Да, отредактируйте `words.json` и удалите строку (весь объект `{ }`).

### Q: Чем ID номера? Нужны ли они?
**A:** Это уникальные номера для каждого слова. Они должны идти по порядку (1, 2, 3...). `add_words.py` автоматически проставляет корректные ID.

## 💾 Формат JSON (справка)

```json
{
    "id": 1,                              // Уникальный номер (обязателен)
    "word": "hello",                      // Слово на английском (обязателен)
    "translation": "привет",              // Перевод (обязателен)
    "association": "Привет, герой!",      // Мнемоническая ассоциация (опционально)
    "example": "Hello, my friend!",       // Пример использования (опционально)
    "ipa": "/həˈloʊ/"                     // IPA транскрипция (опционально)
}
```

## 📝 Шпаргалка по JSON синтаксису

❌ **Неправильно:**
```json
{"id": 1, "word": "hello"},  // Запятая в конце последнего элемента!
```

✅ **Правильно:**
```json
{"id": 1, "word": "hello"}   // Нет запятой в конце!
```

❌ **Неправильно:**
```json
[
    {"id": 1, "word": "hello"}
    {"id": 2, "word": "world"}  // Отсутствует запятая!
]
```

✅ **Правильно:**
```json
[
    {"id": 1, "word": "hello"},
    {"id": 2, "word": "world"}   // Запятая есть!
]
```
